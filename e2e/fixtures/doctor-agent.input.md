Здравствуйте! Хотим заказать доработку для нашей клиники.

У нас есть МИС (медицинская информационная система) «МедСофт», в которой врачи ведут приёмы. Хотим два блока, которые будут с ней связаны.

Первый блок — помощник по рекомендациям. Врач на приёме ставит диагноз по МКБ-10, и система должна подсказывать, какие обследования и анализы назначить, к каким смежным специалистам направить и какие общие рекомендации дать пациенту. Подсказки должны опираться на официальные клинические рекомендации, а не на выдумку. Врач всегда принимает финальное решение сам, система только подсказывает — обязательно нужен дисклеймер «решение принимает врач». Результат приёма (диагноз, подсказки) должен автоматически сохраняться в карточку пациента в «МедСофт», чтобы не переносить вручную.

Второй блок — голосовой помощник на приёме. Врач нажимает кнопку «Начать запись» в веб-интерфейсе, идёт запись разговора врача с пациентом, речь распознаётся и автоматически раскладывается по разделам протокола приёма (жалобы, анамнез заболевания, анамнез жизни и т.д.). Сейчас врач не видит, что распознаётся, пока не остановит запись — хотим, чтобы текст распознавания был виден по разделам в реальном времени прямо во время приёма, чтобы врач замечал ошибки сразу.

Важные детали:
- Приёмник звука — приложение для Windows на компьютере врача (не отдельное устройство), с внешним USB-микрофоном.
- Данные пациентов персональные: по 152-ФЗ обработка и распознавание должны идти на сервере в РФ. Обезличивание делаем на нашей стороне до передачи.
- Сеть в клинике: наружу только исходящие подключения, входящие порты открывать нельзя.
- Прямого доступа к «МедСофт» у вас пока нет: есть публичная документация API, доступ ограничен по IP, можем поднять для вас виртуальную машину в нашей сети или дать удалённый доступ.
- Второй блок (голос) хотели бы сделать вторым этапом, после первого.

Бюджет и сроки пока не фиксировали, сначала хотим понять объём и стоимость. Готовы на платный технический аудит в начале.

Нам нужен от вас понятный документ (ТЗ), который можно передать разработчикам.
